# 🎓 Fall 26 | Section 68_F Study Portal

A dynamic, real-time auto-updating academic course portal built for the students of **Department of CSE, Daffodil International University (Section 68_F)**. 

This portal organizes and fetches course-related PDFs, slides, and materials directly from Google Drive without requiring any API keys or backend servers.

🔗 **Live Website:** [Visit the Study Portal](https://parveshasan1.github.io/CSE68/)

---

## 🚀 Key Features

* **Real-Time Google Drive Sync:** Files uploaded, deleted, or renamed in the designated Google Drive folders automatically sync to the website in real-time.
* **No API Key Required:** Utilizes Google Drive's embedded folder view for seamless and secure public access.
* **Categorized Courses:** Materials are neatly organized into Fall 26 specific courses:
  * CSE223 (Digital Logic Design)
  * CSE225 (Data Communication)
  * CSE227 (Systems Analysis and Design)
  * CSE228 (Theory of Computation)
  * CSE224 (DLD Lab)
* **Instant Search:** Quick live search bar to find specific files (e.g., DFD, Logic Gates, Week 3) instantly.
* **Clean UI:** Professional dark-themed interface built with classic 'Times New Roman' typography.

---

## 🛠️ How It Works

The website is a static Single Page Application (SPA) built purely with HTML, CSS, and JavaScript. 
1. It uses `iframe` embedding to display live Google Drive folders.
2. Hardcoded quick-access cards provide immediate links to important syllabus files, reference books, and previous semester questions.
3. Hosted entirely on **GitHub Pages**.
